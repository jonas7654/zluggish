# All-time leaderboards

By default, live results use a 60-minute window and personal records use a 90-day window.

To use all-time leaderboards for both:

1. Set `leaderboards.allTime` to `true` in `zluggish.config.ts`.
2. Start the server again.

Jerseys are still valid for 60 minutes. Zluggish gives a jersey only for a new all-time record.
