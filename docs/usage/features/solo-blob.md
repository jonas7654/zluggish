# Solo blob

A solo blob is a group of bots that rides around you in real time. You do not need a RoboPacer.

The bots ride the same road that you rode, with its real corners, hills and speed. They ride wheel to wheel behind you in the draft. They also rotate: a rider comes up next to you, pulls for some time, then drifts back through the group.

## Chat commands

| Command     | Result                                               |
| ----------- | ---------------------------------------------------- |
| `.blob <n>` | Start a blob of `n` riders, or keep it at that size. |
| `.blob`     | Show the status.                                     |
| `.blob new` | Keep the number of riders, but use new riders.       |
| `.blob off` | Stop the blob.                                       |

## Gestures

The gesture keys change what the group does:

| Gesture    | Key | Result                     |
| ---------- | --- | -------------------------- |
| Elbow      | F1  | The group comes past you.  |
| Hammertime | F4  | Full power, for a segment. |
| I'm toast  | F7  | The group rides easier.    |
| Bell       | F8  | You want a turn in front.  |
