# Bookmarks

When you finish an activity, Zluggish saves your last position as a bookmark.

- To save a bookmark during a ride, type `.bookmark <name>` in the chat.
- To start a new activity from a bookmark, select it in **Join a Zwifter** on the home screen.
- To teleport to a bookmark, use the teleport icon on the action bar.
