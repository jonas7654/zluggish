# Entitlements

Set these options in `zluggish.config.ts`, then start the server again:

| Option                         | Result                                   |
| ------------------------------ | ---------------------------------------- |
| `equipment.unlockEntitlements` | Unlock entitlements (special equipment). |
| `equipment.unlockBikeUpgrades` | Unlock bike upgrades.                    |
| `equipment.unlockAll`          | Unlock all equipment.                    |
